NeoSync is unofficial, independently developed software for transferring

USE AT YOUR OWN RISK.

NeoSync installs a WinUSB driver package for the AlphaSmart Neo's USB
interfaces and modifies Windows Plug and Play driver associations for that
device. This process is generally safe and reversible (uninstalling NeoSync
removes the driver package and restores the device's default Windows
keyboard driver), but as with any software that installs device drivers,
there is inherent risk.

IMPORTANT: once NeoSync's driver is installed, the AlphaSmart Neo will no
longer function as a standalone USB keyboard on this computer (its "send
text" feature) until the driver is removed again (Advanced > Remove WinUSB
drivers in NeoSync). This is a deliberate tradeoff required to communicate
with the device for file transfer.
